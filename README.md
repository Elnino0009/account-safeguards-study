# Account safeguards study

Research instrument for a preregistered study of consumer acceptance of AI agents that
can refuse or initiate financial actions. Static files, no build step, no dependencies.

Everything shown to a participant is hypothetical: no real accounts, no real money, and
no AI acts at any point. The consent screen states the review route in full.

Protocol, analysis code, and the ethics self-assessment live in the researcher's project
repository and are available on request.
